# ♟️ Chess Competition Dashboard | Power BI

An interactive **Chess Competition Dashboard** built using Microsoft Power BI to analyze player performance, game results, tournaments, and different chess formats.

The dashboard transforms chess competition data into meaningful visual insights through interactive charts, KPIs, and filters.

## 🎯 Project Objective

The objective of this project is to analyze chess competition data and provide an interactive dashboard that helps users understand:

- Overall game performance
- Player participation
- White vs Black performance
- Wins, losses, and draws
- Tournament-wise game distribution
- Player-wise games played
- Performance across different chess formats

---

## 📈 Key Dashboard Features

### 🏆 Overall Performance
- Total Players
- Total Games
- White Wins
- Black Wins
- Draw Percentage

### ♟️ Game Analysis
- Game result distribution
- White vs Black wins comparison
- Player-wise games played
- Tournament-wise games

### 🎮 Format Analysis
Analysis across different chess formats:

- Classical
- Rapid
- Blitz

### 🔎 Interactive Filters

Users can interact with the dashboard using:

- Tournament
- Game Format

These filters dynamically update the dashboard visuals.
